iPhone & Android

Add it to your home screen

No download needed. This installs the portal as an app icon using your browser.

  1. Android (Chrome): open nbanaapp.eu.cc, tap the ⋮ menu, then Add to Home screen → Install.
  2. iPhone (Safari): open the site, tap Share, scroll down, then Add to Home Screen.
  3. Open the new NBANA icon on your home screen and sign in as usual.
Android app

Turn on app updates

So the app can update itself later without going through the Play Store, Android needs your permission once. The app will guide you the first time you open it.

  1. Open Settings on your phone.
  2. Go to Apps → Special access → Install unknown apps.
  3. Find NBANA Portal — or the browser you downloaded it with (for example Chrome).
  4. Turn Allow from this source on.
  5. Return to the app. Updates will now install on their own.

This setting is standard for Android apps installed outside the Play Store. It is safe and you can switch it off anytime.

For the school admin: how to build the .apk
  1. Open pwabuilder.com and enter https://nbanaapp.eu.cc.
  2. Click Start. It reads this site's manifest.json and service worker automatically.
  3. Choose Package for stores → Android → Download. It generates a signed package and the signing key — keep the key safe for future updates.
  4. Rename the file to NBANA-app.apk and save it in this website's folder (next to app.html), then commit and push.
  5. Reload this page: the download button appears by itself. Build a fresh APK the same way whenever you want to push an update.

Command-line alternative: npx @bubblewrap/cli init --manifest https://nbanaapp.eu.cc/manifest.json then npx @bubblewrap/cli build.

Packing the site in a plain WebView instead? Point it at https://nbanaapp.eu.cc/portal.html?app=1 and add the token NBANAApp to the WebView user agent. That is how the app knows it is the app: it keeps the full-screen app layout and shows the one-time update-permission screen on first launch.
